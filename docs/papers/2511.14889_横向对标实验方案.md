## 一、论文本身要求多少配置、多少轮

| 维度 | 论文设置 |
|---|---|
| 地面站 | 13 站网络（IGS 启发），子集 **1 / 2 / 3 / 5 / 10 / 13** 共 **6 档** |
| 卫星 | 簇数 {1,2,5,10} × 每簇卫星数 {1,2,5,10} = **16 种星座配置**（有效 15 种，单星无法 FL），总卫星数 **1–100 颗** |
| 算法变体 | **8 个**：FedAvg/FedProx/FedBuff 三种 space-ified + 调度/最小 epoch/簇内通信增强组合 |
| 训练轮次 | **每配置最多 500 轮，或 3 个月仿真时间，先到者为准** |
| 随机种子 | **5 个/配置** |
| 总运行数 | 8 变体 × 96 配置 × 5 seeds = **768 组 × 5 = 3840 次** |
| 仿真周期 | 2024-04-14 ~ 2024-07-13（3 个月） |

> 结论：论文的完整横向对比需要 **6 档基站（1–13）+ 16 种卫星配置（1–100 星）+ 500 轮 + 5 seeds**。
> 但“证明本平台可靠”不需要一次跑满 3840 次，按下面分级即可。

## 二、我们项目要跑多少（分级方案）

> 设计原则：每个阶段都以论文的 **EP 图（准确率/轮次时长/空闲时间）** 为对照物，
> 用最少的运行覆盖论文的三条核心结论：①基站数量是第一驱动；②簇内规模 > 簇数量；③调度/最小epoch 的效果。

| 阶段 | 运行次数 | 配置 | 变体 | 种子 | 用途 |
|---|---|---|---|---|---|
| **T0 最小可信对标** | **72** | 5 簇 × 10 星 = **50 星**，GS = {1,2,3,5,10,13} | FedAvg、FedProx、FedBuff、FedAvgSch | 3 | 基站效应 + 调度加速；对标论文 Fig.4/6/7 |
| **T1 推荐对标（热图）** | **225** | GS = 13，**15 种有效星座**（簇数×每簇星，1–100 星） | T0 四个 + FedProxSchV2（5 变体） | 3 | 生成论文同款 4×4 热图：准确率/轮次时长/空闲时间（对标 Fig.5/8/10 的 GS=13 面板） |
| **T1b 统计强化** | **+120** | 关键配置 (5,10) 与 (10,10)，GS 全 6 档 | 5 变体 | 补 2 → 共 **5 seeds** | 均值±标准差，满足论文同级的统计强度 |
| **T2 簇内通信（可选）** | **+90** | GS = 13，15 种星座 | FedAvgIntraSL、FedProxIntraSL | 3 | 验证 FLIntraCC 收益（需先实现星间链路模型） |
| **T3 论文全量（可选）** | 3840 | 8 变体 × 96 配置 | 全部 | 5 | 完整复刻论文全部热图 |

- T0–T2 去重后约 **495 次运行**（配置有重叠）；先跑 T0（约半天机器时间）验证流水线，再补 T1 热图。
- **窗口表只生成一次**：16 种星座配置（15 有效）× 6 档 GS 子集，3 个月访问窗口，所有变体与 seeds 复用。
- 若时间很紧：**只跑 T0 + T1 的 FedAvg/FedProx/FedBuff/FedAvgSch 四个变体**，也能覆盖“GS 效应 + 调度 + 空闲时间”三条对照。

### 每次实验的固定运行参数（与论文对齐）

| 项 | 取值 |
|---|---|
| 轨道 | Walker-Star，500 km、90° 倾角、e=0，簇内均匀真近点角、簇间均匀 RAAN |
| 数据 | FEMNIST，writer 级 Non-IID，每星 200–350 样本 |
| 模型 | 47k 参数（建议 784-60-10 MLP；论文未给结构，需在报告声明） |
| 每轮客户端数 C | 10 |
| 时间模型 | 计算 98 MFLOPs/epoch @40 GFLOPS ≈ 2.45 ms；模型 186 KB @580 Mbps ≈ 2.6 ms；接触窗口按轨道几何 |
| 轮次上限 | 500 轮或 3 个月仿真，先到者截止 |
| 评估 | 每轮评估；评估客户端选择与训练一致 |
| 种子 | T0–T1 用 3 个（如 42/43/44），T1b 补到 5 个 |

### 关键指标口径（必须统一，否则对比无效）

| 指标 | 口径 |
|---|---|
| 最大聚合准确率 | 整个运行中所有评估轮次的最大值（0–1） |
| 每轮时长 | 从开始发送全局模型到本轮聚合完成的**仿真时间差**（小时） |
| 空闲时间 | 单星既不在计算、也不在通信的**仿真时间**（小时，per-satellite 平均） |
| 到达 80% 的轮次/天数 | 首次达到 0.8 准确率的轮次与仿真天数（9× 加速的核心对比量） |
| 仿真时间 | 用 STK/轨道库生成的窗口时间轴推进，**不是墙钟** |

## 四、验收标准（写进报告，证明“平台可靠”）

| 编号 | 验收项 | 判定标准 |
|---|---|---|
| C1 | 基站效应 | GS 增加 → 轮次时长单调下降；5→13 站改善 <10%（收益递减） |
| C2 | 簇结构效应 | 固定总星数时，每簇卫星数↑ 比簇数↑ 更能缩短轮次时长 |
| C3 | 调度加速 | (10,10)+13GS 下 FedAvgSch 相对 FedAvg 到达 500 轮的仿真时间加速 **≥3×**（论文约 9×，方向一致、量级可解释） |
| C4 | 空闲时间排序 | mean idle：FedBuff < FedProx < FedAvg（GS=13 面板） |
| C5 | 精度区间 | GS=13 大星座 max accuracy 0.70–0.90；GS=1 约 0.55–0.75（与论文 Fig.4 同量级，容差 ±0.10） |
| C6 | 最小 epoch 修正 | FedProxSch 在高 GS 下低于 FedProx；FedProxSchV2 回升 |
| C7 | 种子稳定性 | 同配置 3–5 seeds：max accuracy 标准差 ≤0.03；轮次时长变异系数 ≤20% |
| C8 | 平台可复现性 | 同配置同 seed 重复运行差异 <1e-3（日志级可复现） |

**横向对比容差建议**：
- 准确率（FedAvg，GS=13，与 Fig.4 逐格对照）：15 个有效配置上 **平均绝对误差 ≤0.10**，Spearman 秩相关 **≥0.6**；
- 轮次时长：均值相对差 **≤30%**，单格 ≤50%；重点看 GS/簇结构趋势是否同向；
- 空闲时间：排序关系（C4）与 FedBuff 相对 FedAvg 降幅 **≥50%**。

差异必须归因到四类之一并在报告中声明：①窗口生成（STK vs 开源轨道库、最小仰角/步长）②模型结构 ③FL 超参 ④评估频率/口径。

## 五、我们平台当前差距（要补什么才能跑）

| 能力 | 现状 | 需要补 |
|---|---|---|
| Walker 星座 + 13 站 | `fl_space/orbit`、`environment` 已有基础 | 多簇/每簇星参数化 + Table 3 站址 + 6 档子集 |
| 3 个月访问窗口 | `fl_space/simulator/contact_matrix.py` 有逐时隙接触矩阵 | 长时段窗口导出（CSV）+ 最小仰角/步长可配 |
| FedAvg/FedProx/FedBuff | `fl_space/fl/` 已有三种算法 | 空间化客户端选择/轮次完成/异步陈旧度层（Alg.1–5） |
| 调度/簇内通信 | `fl_space/fl/scheduler.py` 有通信调度雏形 | FLSchedule 策略 + FLIntraCC 星间中继 |
| 时间模型 | `fl_space/fl/time_model.py` | 事件驱动仿真时钟（计算/传输/空闲记账） |
| 热图/曲线分析 | `fl_space/viz` + 本平台分析器 | 三张 4×4 热图 + 对照表生成脚本 |

**最快路径（先证明轨道/通信子系统可靠）**：只做“多簇 Walker + 13 站 + 3 个月窗口 + 客户端选择调度”，
直接输出**轮次时长热图**与 **GS 效应曲线** 对照论文 Fig.8/Fig.4(b) —— 这一步不依赖 FL 训练，1–2 天可完成，
是最有说服力的第一块横向对比证据；之后再补 FL 精度/空闲时间。

## 六、结论（可直接回复导师/评委的一句话）

> 论文的完整设置是 **6 档地面站（1–13 个）+ 16 种卫星配置（1–100 颗）+ 500 轮或 3 个月仿真 + 5 seeds，
> 共 768 组配置 × 5 = 3840 次运行**。为证明本项目可靠性并做横向比较，我们按 **T0（72 次）/ T1（225 次）/
> T1b（+120）/ T2（+90）** 的分级方案（约 495 次运行，成本约为论文全量的 13%），
> 输出与论文同量纲的 **三张热图（准确率/轮次时长/空闲时间）+ 准确率-轮次/时间曲线 + 与论文的数值对照表 +
> 趋势一致性检验与差异归因报告**，并用 C1–C8 八项验收标准判定可靠性与一致性。
