## 2. 部署方案（三选一，按可得资源排序）

### 方案 A：本机 + Cloudflare 快速隧道（今天可出链接，零成本）

- `deploy/install_public_demo.ps1` 自动下载 cloudflared、启动服务器（`SPACEFL_PUBLIC_DEMO=1`）、
  建立 `https://<random>.trycloudflare.com` 隧道，并写 URL 到 `deploy/public_url.txt`；
- 注册 Windows 计划任务每 5 分钟保活（服务器/隧道任一掉线自动重启）；
- **优点**：5 分钟上线、无需账号、功能完整；
- **风险**：URL 为随机子域名（进程重启会变）；本机需保持开机联网。
  → 提交前把当前 URL 写入材料，并在提交说明注明"比赛期间保活"。

### 方案 B：Hugging Face Spaces（稳定链接，推荐有 HF 账号时）

- 用 `Dockerfile` + `SPACEFL_PUBLIC_DEMO=1` 部署为 Docker Space；
- **优点**：链接永久稳定、评委随时打开；**需要** HF Token / 账号；
- 需要把 `文献/`、索引与演示档案随镜像打包（或启动时生成）。

### 方案 C：用户自己的云服务器/域名（最稳）

- 提供 SSH 与服务器后，用 `deploy/systemd/spacefl.service` + Nginx/Caddy 反代 + HTTPS；
- **优点**：链接可控、可绑域名；**需要**服务器与域名。

> 决策原则：先用 A 拿到可提交链接，同时并行准备 B/C；11-08 前确定最终链接。

## 3. 公网演示安全加固（已实现 / 待验证）

公网实例设置 `SPACEFL_PUBLIC_DEMO=1` 后：

- **只读白名单**：仅允许 Agent 规划/分析/对话、文献问答/精读、情报刷新/简报；
  训练任务、文献导入、配置修改、实验删除、目录修改、CC Switch 导入等**全部 403**；
- **限流**：LLM 相关接口每 IP 20 次/分钟；
- **文件读取限制**：文献内容接口只允许文献库根目录索引路径，禁止读取项目内任意文件
  （防止 `.spacefl_ai_config.json` 等泄漏）；
- **情报刷新冷却**：演示模式下强制 120s 内走缓存，避免滥用外网抓取；
- **前端提示**：页面显示"公网演示模式（训练与写操作已禁用）"，并禁用运行计划按钮。

本地文件不是敏感数据时可以开放；如需账号体系（评审专用口令），再加一层 Basic Auth 网关。

## 4. 演示脚本（3 分钟，无 API Key 也能走完）

1. **总览**：Hero 指标（文献 42 / 已解析 42 / 情报 48 / 实验档案 16）+ 研究目标条；
2. **文献库**：搜索「卸载 时延」→ 打开 FedLEO 文献 → AI 精读（贡献/局限/相关度 30/100）→
   右侧提问「FedLEO 的卸载增益在哪些场景下最大？」→ 10 条带页码引用；
3. **前沿情报**：刷新（或读缓存）→ 相关度 100 的 arXiv 论文排前 → 生成情报简报；
4. **研究助手**：输入「对比 FedLEO 数据卸载开启/关闭在 3 轨面 2 星与 3 轨面 3 星下的准确率差异，3 轮，seed 42」
   → 计划卡片（条件表/对照/预计耗时/评审 71 分）→ 说明"公网演示模式不跑新训练"；
5. **结果解读**：点「解读最新档案」→ 指标对照表、证据链、文献引用、尚不能支持的结论、下一步建议。
