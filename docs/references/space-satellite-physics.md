# 太空卫星物理规则参考

这份参考用于扩展 SpaceFL 的任务、卫星和通信模拟。它规定可复用的建模边界，
不把所有规则都强制塞进同一个模拟器。

## 单位与坐标

新任务层统一使用 SI 单位：

| 量 | 单位 | 命名后缀 |
| --- | --- | --- |
| 距离 | m | `_m` |
| 轨道高度 | km | `_km` |
| 速度 | m/s | `_mps` |
| 加速度 | m/s² | `_mps2` |
| 质量 | kg | `_kg` |
| 时间 | s | `_s` |
| 功率 | W | `_w` |
| 面积 | m² | `_m2` |

现有 `environment` / `orbit` 的公共接口继续使用其已有单位。跨层转换必须写在
适配函数中，不要在变量名不变的情况下换单位。

## 轨道规则

基础层可使用二体开普勒模型：

```text
v_circular = sqrt(mu / r)
T = 2π * sqrt(a³ / mu)
```

轨道要素至少包括：

- 半长轴 `a`；
- 偏心率 `e`；
- 倾角 `i`；
- 升交点赤经 `raan`；
- 近地点幅角；
- 初始近点角。

任何涉及真实任务时间、星地窗口或碰撞风险的结论，都必须注明使用
`kepler`、`skyfield/SGP4` 或更高保真后端。

## 发射和级间规则

火箭性能初估可使用：

```text
delta_v = Isp * g0 * ln(m_initial / m_final)
```

多级火箭必须按级计算，并明确：

- 每一级的干质量、推进剂质量、比冲、推力和燃烧时间；
- 上面级与有效载荷的堆叠质量；
- 整流罩和适配器是否计入有效载荷质量；
- 重力、阻力、转向损失是否作为显式参数。

不得用单一“成功率”替代轨迹、质量和推进预算。成功率可以作为经营模拟规则，
但不能改写物理计算结果。

## 卫星模型

卫星设计分成两部分：

1. **物理设计**：质量、推进剂、功率、迎风面积、阻力系数、存储容量；
2. **视觉设计**：基础几何、尺寸、颜色、模型文件 URI、渲染缩放。

自定义外观不应自动改变质量或阻力。若用户希望外观决定物理参数，应显式提供
`VisualToPhysics` 转换器并在结果中记录转换规则。

## 大气和阻力

快速原型可以使用：

```text
rho(h) = rho_0 * exp(-h / H)
q = 0.5 * rho * v²
D / m = q * Cd * A / m
```

指数模型不适合太阳活动显著、再入或精确寿命预测。高保真扩展要替换大气模型，
不能仅把 `H` 调成一个“看起来合理”的数字。

## 通信和激光链路

卫星通信模型至少要区分：

- 星地链路和星间链路；
- 可见性/视线；
- 指向、捕获和跟踪；
- 带宽、发射功率、接收灵敏度和链路预算；
- 天线/光学终端并发能力；
- 遮挡、天气和云量对星地光链路的影响。

缺少 SpaceX 官方工程参数时，参数必须标记为 `assumption`，并保留来源和范围。
不要把公开宣传中的峰值吞吐量直接作为每颗卫星持续可用带宽。

## 保真度标签

每个研究结果建议携带以下标签之一：

- `toy`：用于接口和教学；
- `first_order`：一阶物理估算；
- `kepler`：二体轨道传播；
- `sgp4`：基于 TLE 的传播；
- `high_fidelity`：经过验证的高保真后端。

不同保真度的结果不能在同一张图中混合而不标注。
