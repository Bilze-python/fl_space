# SpaceFL 科研智能平台 · 6 分钟演示视频录制方案与讲稿

> 作品链接：https://spacefl-research-agent.onrender.com
> 视频定位：**以"仿真实验"为主线**，展示"文献/情报 → 实验设计 → 批量执行 → 结果解读 → 结论边界"的科研闭环。
> 建议成片：1920×1080、30fps、6:00±10s；讲解为主、操作画面为辅。

---

## 一、核心信息（先定调，再录制）

### 一句话定位

**SpaceFL 是一个面向低轨卫星联邦学习的科研智能体：把"查文献、追前沿、设计仿真实验、跑批量实验、解读结果"连成一条可追溯、可复现的闭环。**

### 三个核心创新点

1. **科研意图 → 结构化仿真实验计划**
   用户用自然语言描述研究问题，智能体生成含"假设 / 变量 / 对照 / 指标 / 轮次 / 种子 / 风险 / 预计耗时"的计划，并给出计划评审分数——把"会写脚本的人才能做实验"变成"说清楚问题就能开始设计实验"。

2. **文献—情报—实验—结论的证据链**
   实验计划引用文献依据；结果解读给出指标对照、文献引用和**"尚不能支持的结论"**；把"跑出一个数"升级为"可解释、可审阅的科研结论"。

3. **面向真实科研流程的可靠性与可部署性**
   平台支持批量实验与档案管理，并以 405 次完成实验、194,992 轮训练、0 失败、代表性配置同种子零差异复现，证明流程可复现；公网只读演示模式保证评审可安全访问，本地完整版可运行真实仿真。

### 作品价值

- **降门槛**：不需要先写实验脚本，先把研究问题说清楚；
- **提效率**：实验设计、批量运行、报告整理一体化，缩短"想法→结果"的周期；
- **保可信**：引用可追溯、指标可复核、结论边界显式声明；
- **可复用**：同一套流程可用于论文对标、课程实验、项目验收与团队协作。

### 目标观众

比赛评委（主）、科研/工程同学（次）。讲解要"少术语、多因果"，每个功能都回答"它帮研究者解决了什么"。

### 2. 演示前预热（非常重要）

Render 免费实例空闲会休眠，**首次打开可能 30–60 秒**：

1. 录制前 2–3 分钟打开 `https://spacefl-research-agent.onrender.com`；

3. 确认右上角显示"已同步本地数据"，Hero 指标为 **6 篇文献 / 6 全文解析 / 48 情报 / 3 实验档案**；
4. 确认"研究助手"页出现"公网演示模式 · 只读"提示，运行计划按钮为禁用状态（这是设计而非故障）。

### 3. 备选素材（防止现场卡顿）

- 预录 10–15 秒本地完整版运行实验的 B-roll：`start_spacefl.bat` → 研究助手 → 运行计划 → 进度/结果；

- 准备一张"405 次实验 / 194,992 轮 / 0 失败"的图表页（可用 `docs/analysis/` 下的图）。

## 四、完整讲稿（按时间轴，可直接照读）

> 本段讲稿约 1,527 个汉字，按 250–260 字/分钟约 6 分钟；实际录制时页面等待会占用时间，
> 建议：① 操作提前练熟、减少等待；② 若超时，优先压缩 2:55–3:35 文献/情报段与 5:10–5:45 价值段；
> ③ 不要为赶时间删掉"尚不能支持的结论"和"公网只读/本地可执行"两句。

> 语速建议：每分钟 240–270 字；括号内是操作提示，不要念出来。

### 0:00–0:30 开场

（画面：片头标题 + 作品链接）

"各位评委好，我是 SpaceFL 科研智能平台的开发者。今天用 6 分钟，演示我们如何用 AI 智能体，把太空联邦学习的仿真实验，从'写脚本、跑任务、整理结果'，变成一条可追溯、可复现的科研闭环。作品链接是 spacefl-research-agent.onrender.com，评委可以直接打开体验。"

### 0:30–1:05 总览

（操作：打开首页，鼠标依次划过 Hero、指标、研究目标、流程条）

"这是平台的总览页。当前演示环境预置了 6 篇文献、48 条前沿情报和 3 个实验档案。中间是研究目标：研究低轨卫星星座中，星地链路受限条件下的联邦学习数据卸载与聚合策略。平台把科研流程拆成四步：文献与情报输入、实验设计、批量执行、结果解读。下面我从'实验'这条主线开始演示。"

### 1:05–2:05 核心创新 1：自然语言 → 仿真实验计划

（操作：进入"研究助手"，在输入框输入下面这句话，点击"生成实验计划"）

输入示例：
"对比 FedLEO 数据卸载开启和关闭，在 3 轨面 2 星与 3 轨面 3 星两种拓扑下的准确率差异，跑 3 轮，seed 42，并说明需要控制哪些变量。"

（等待计划卡片出现，鼠标依次指向标题、假设、条件表、评审分）

"我不用写配置文件，直接用自然语言描述研究问题。智能体把这句话变成结构化实验计划：研究假设、实验条件、对照组、训练轮次、随机种子、评价指标，以及预计耗时。它还会对计划做评审，指出样本量、对照是否充分、结论风险。这一步的价值是：**把实验设计从'个人经验'变成'可讨论、可复用的结构化方案'**，而且计划里的每个参数都能对应到任务配置，后面执行不会走样。"

### 2:05–2:55 核心创新 2：实验档案 → 结果解读

（操作：进入"实验档案"，选择最新的 FedLEO 卸载对照档案，点击"解读最新档案"）

"实验跑完不是终点。这是平台预置的实验档案：同一配置下，开启和关闭数据卸载的对照结果。点击'解读'，平台会给出：两组的准确率、差值、样本守恒、时延与通信开销；更重要的是，它会把结论和文献对照，并明确写出——**哪些结论现在还不能支持**，比如单种子、5 轮的结果不能说明统计显著性。"

（鼠标指向"尚不能支持的结论"和引用区域）

"这是我们和普通实验脚本最大的区别：**不仅给结果，还给证据链和结论边界**。评委和审稿人可以看到每个数字从哪里来、能推到哪一步、不能推到哪一步。"

### 2:55–3:35 知识底座：文献与情报

（操作：进入"文献库"，搜索"卸载"，打开第一篇，展示精读摘要/贡献/局限，然后在右侧提问）

搜索词："卸载 时延"

提问示例："FedLEO 的卸载增益在哪些场景下最大？"

"实验设计需要依据。文献库支持全文检索、AI 精读和带页码引用的问答。比如我问 FedLEO 的卸载增益在哪些场景最大，回答会给出引用来源，而不是泛泛而谈。前沿情报页则把 arXiv 和航天资讯按研究目标相关度排序，帮助我们在设计下一组实验前，知道领域里刚发生了什么。"

### 3:35–4:20 从设计到执行：公网只读与本地完整版

（操作：回到研究助手，尝试点击"运行计划"，出现只读提示；然后切本地完整版 B-roll）

"公网演示为了安全，训练和写操作是禁用的，所以这里会提示'演示模式只读'。但同一份计划，在本地完整版里可以一键提交后台批量执行：平台会按条件表逐组运行、写进度、保存每个 run 的配置、日志和结果。**公网负责展示与评审，本地负责真实计算**，这是我们对部署安全的取舍。"

（如有本地 B-roll：展示运行计划、进度条、结果卡片，3–5 秒即可）

### 4:20–5:10 核心创新 3：可靠性与可复现

（画面：切到可靠性数据图/报告截图；或回到总览展示实验档案数量）

"科研智能体不能只会'生成文本'，还要经得起复核。我们用一批横向对标实验验证了平台：**405 次完成实验、194,992 轮训练、0 失败**；相同配置和随机种子下，代表性实验的历史、事件和模型参数做到了零差异复现。我们也如实记录局限：当前是项目现有实现的近似实验，时间模型按 60 秒槽取整，不能宣称论文级数值复现，更不能把'近似'包装成'严格复现'。**这种可复现、可审计、又敢于声明边界的能力，才是科研场景真正需要的可靠性。**"

### 5:10–5:45 价值总结

（画面：四宫格文字：降门槛 / 提效率 / 保可信 / 可复用）

"总结一下平台的价值：第一，降门槛，把研究问题说清楚就能开始设计实验；第二，提效率，设计、执行、解读、归档在同一个工作台完成；第三，保可信，文献引用、指标口径和结论边界都可追溯；第四，可复用，同一套流程可以用于论文对标、课程实验和团队协作。它服务的不只是某一次实验，而是整个太空联邦学习的科研工作流。"

### 5:45–6:00 结尾

（画面：作品链接 + 开源仓库 + "谢谢"）

"以上就是 SpaceFL 科研智能平台的 6 分钟演示。作品链接和开源仓库都在画面上，欢迎评委老师打开体验、提出建议。谢谢！"

## 五、录制操作卡（照着点即可）

1. 打开 `https://spacefl-research-agent.onrender.com`，等 Hero 指标出现（冷启动最多 60 秒）；
2. 首页停留 20–25 秒，鼠标缓慢划过 Hero、指标、研究目标、流程条；
3. 点顶部"研究助手"→ 等演示模式提示出现 → 粘贴输入 → 点"生成实验计划"→ 等卡片；
   - 鼠标依次指向：标题、假设、条件表、评审分、文献引用；
4. 点顶部"实验档案"→ 选最新档案 → 点"解读最新档案"→ 等卡片；
   - 重点指："指标对照"、"证据链/引用"、"尚不能支持的结论"；
5. 点顶部"文献库"→ 搜索"卸载"→ 打开第一篇 → 点"AI 精读"→ 右侧提问；
   - 提问后等引用出现，指一下页码/来源；
6. 点顶部"前沿情报"→ 展示相关度排序 → 停留 3–5 秒；
7. 回"研究助手"→ 点"运行计划"→ 出现只读提示 → 说"本地完整版可执行"；
8. （可选）切本地完整版 B-roll 10–15 秒；
9. 切可靠性图表页 3–5 秒；
10. 回首页/结尾页，展示链接，结束。
