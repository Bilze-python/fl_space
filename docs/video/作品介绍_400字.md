# 作品介绍（两个版本，按提交系统口径选用）

## 版本 A：约 400 字符（含标点与链接共 401 字符，适合严格字符限制）

SpaceFL 科研智能平台是面向低轨卫星联邦学习的可部署科研智能体，把仿真实验做成可追溯、可复现的闭环。平台内置期刊知识库，支持全文检索、AI 精读与带页码引用的问答；前沿情报按研究目标自动重排；用户用自然语言提出研究问题，智能体生成包含假设、变量、对照、指标、轮次、种子与风险的结构化实验计划，并给出可执行的计划评审意见。实验完成后，平台解读档案：指标对照、证据链、文献引用，以及明确标注"尚不能支持的结论"，避免把近似实验包装成论文复现。平台在 405 次实验、194,992 轮训练中零失败；代表性配置同种子复现时，历史、事件与模型参数零差异。已部署为公网只读演示（https://spacefl-research-agent.onrender.com），可直接体验文献精读、实验规划与档案解读；本地完整版可运行真实批量仿真实验。其价值在于降低实验门槛、加快迭代，让科研结论更可解释、更可复核。

## 版本 B：约 400 汉字（含标点共 462 字符，适合按"汉字字数"计数）

SpaceFL 科研智能平台是面向低轨卫星联邦学习与星地链路仿真的可部署科研智能体，核心是把仿真实验做成一条可追溯、可复现、可审阅的闭环。平台内置期刊文献知识库，支持全文检索、AI 精读与带页码引用的知识库问答；前沿情报按研究目标自动重排，帮助研究者在设计实验前掌握领域动态。用户用自然语言提出研究问题，智能体会生成包含研究假设、变量、对照、评价指标、轮次、随机种子与风险提示的结构化实验计划，并给出可执行的计划评审意见。实验完成后，平台对实验档案进行解读，输出指标对照、证据链、文献引用，以及明确标注的"尚不能支持的结论"，避免把近似实验包装成论文复现。可靠性方面，平台在 405 次完成实验、194,992 轮训练中保持零失败，代表性配置同种子复现时历史、事件与模型参数零差异。平台已部署为公网可访问的只读演示（链接见提交材料），评委可直接体验文献精读、实验规划与档案解读；本地完整版可运行批量仿真实验。其价值在于降低太空联邦学习实验门槛、加快研究迭代，并让科研结论更可解释、更可复核，可服务于论文对标、课程实验与团队协作。
