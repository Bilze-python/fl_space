      训练算力

      在电脑启动 SpaceFL 本地连接器，再填入它显示的配对码。训练使用该电脑的 CPU / CUDA，原始图片和完整结果保存在本机。请保持程序运行。

      尚未连接电脑

      启动和导入方法

      在安装了 SpaceFL 和 PyTorch 的项目目录中执行（Windows 示例）：

      .\venv\Scripts\python.exe -m web.local_worker connect --device auto

      连接器默认连接公网平台；测试本站可在命令后添加 。自定义图片 ZIP 请在本机导入：

      .\venv\Scripts\python.exe -m web.local_worker import "D:\data\satellite.zip" --name "卫星影像"

      ZIP：train/类别/图片、test/类别/图片，至少两个相同类别，JPG/PNG。导入后约 3 秒同步到数据集选项。内置数据集首次使用时在本机下载。配对有效期 12 小时；平台重启后需重新配对，本地结果仍保留。

      卫星影像数据

      课题组共享训练空间：成员可以查看组内上传的数据、训练配置和结果。访客可以浏览演示。

      ZIP 结构：train/类别/图片、test/类别/图片；至少两个相同类别。导入后选择数据集并保存 Session。

      单星数据偏好

      类别以逗号分隔；FEMNIST 保留 writer 身份，仅应用单星样本上限。
