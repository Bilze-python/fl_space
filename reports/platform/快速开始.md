## 🛠️ 常用命令

### 启动服务
```bash
python -m web.server --host 127.0.0.1 --port 8700
```

### 后台运行
```bash
python -m web.server > web/server.stdout.log 2> web/server.stderr.log &
```

### 停止服务
```bash
# 查找进程
ps aux | grep "python.*server"

# 停止进程
kill <PID>
```

### 查看日志
```bash
tail -f web/server.stderr.log
```

## 🆘 遇到问题？

### 服务无法访问
1. 检查服务是否运行: `curl http://127.0.0.1:8700/api/health`
2. 检查端口占用: `netstat -ano | grep 8700`
3. 查看错误日志: `cat web/server.stderr.log`

### 前端加载失败
1. 清除浏览器缓存
2. 检查浏览器控制台
3. 确认服务正常运行

### API 报错
1. 检查请求格式
2. 查看服务日志
3. 验证数据完整性
