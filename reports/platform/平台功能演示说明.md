```
│                                                │
│ [重置为默认值]                                  │
└────────────────────────────────────────────────┘
```

### 操作说明
- **修改参数**: 直接在表单中编辑
- **保存同步**: 点击"保存到终端 Session"自动写入 `.fls_session.json`
- **从终端刷新**: 读取终端最新配置
- **重置**: 恢复所有参数为默认值

### 与终端联动
```bash
# 网页修改参数后，终端直接使用
fls run train  # 自动使用网页保存的参数

fls tune lr 0.001
fls mount algo fedprox
# 网页点击"从终端刷新"
```

## 🔄 工作流示例

### 场景 1: 快速验证 FedLEO

1. **配置参数** (实验配置页)
   ```
   轮次: 30
   数据集: mnist
   算法: fedavg
   ```

2. **运行实验** (实验总览页)
   - 点击"运行 FedLEO 验证"
   - 设置种子: 42
   - 提交任务

3. **查看结果** (实验档案页)
   - 等待实验完成
   - 查看准确率曲线
   - 分析卸载效果

4. **AI 分析** (AI 解读页)
   - 选择刚完成的实验
   - 提问: "卸载是否有效？"
   - 获取智能建议

### 场景 2: 对比不同配置

1. **运行实验 A**
   ```
   算法: fedavg
   卫星数: 10
   地面站: 5
   ```

2. **运行实验 B**
   ```
   算法: fedprox
   卫星数: 10
   地面站: 5
   ```

3. **对比分析**
   - 在实验档案页选择两个实验
   - 查看准确率曲线对比
   - 分析性能差异
