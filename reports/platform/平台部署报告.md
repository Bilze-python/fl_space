## 🔧 配置 DeepSeek API（可选）

如果要使用 AI 实验解读功能：

```bash
# Windows
set DEEPSEEK_API_KEY=sk-your-api-key-here
python -m web.server

# Linux/Mac
export DEEPSEEK_API_KEY=sk-your-api-key-here
python -m web.server
```

或者在启动命令中设置：
```bash
DEEPSEEK_API_KEY=sk-your-api-key-here python -m web.server
```

**重要提示**: 
- 不要将 API 密钥提交到代码仓库
- 测试完成后建议在 DeepSeek 控制台轮换密钥
- 密钥只用于服务器端调用，不会暴露给前端
