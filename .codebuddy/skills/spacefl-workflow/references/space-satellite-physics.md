# Space Satellite Physics Routing

这是 skill 的工作路由。完整规则维护在：

- `docs/references/space-satellite-physics.md`
- `docs/SPACE_MISSION_FRAMEWORK.md`

执行涉及卫星、火箭、发射、部署或通信的任务时，必须先确认：

1. 新任务层的距离、质量、时间、速度和功率单位；
2. 采用 `toy`、`first_order`、`kepler`、`sgp4` 还是更高保真后端；
3. 学习任务是否以数据、模型、卫星轨道、基础设施和调度为顶层组织；
4. 物理参数、视觉参数和经营规则的边界；
5. 外部 SpaceX API 字段是否只是目录数据，以及是否保存来源和快照时间。

最低物理约束：

- 圆轨道速度使用 `sqrt(mu / r)`；
- 二体轨道优先使用六根数：半长轴、偏心率、倾角、升交点赤经、近地点幅角、近点角；
- 火箭分级速度预算使用齐奥科夫斯基公式；
- 质量、迎风面积和阻力系数必须显式存在；
- 星地/星间链路必须分别处理可见性、指向、频段、带宽、速率和遮挡；
- 未公开的工程参数标记为 `assumption`，不能伪装成 SpaceX 官方规格。
