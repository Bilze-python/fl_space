## CLI 三层架构重构

将原有 7 个扁平子命令重构为 3 层结构：

```
fls tune <参数> <值>    — 调参指令（lr, rounds, epochs, batch, mu, seed, ...）
fls mount <组件> <值>   — 挂载指令（algo, isl, backend, body, distribution, ...）  
fls run <实验类型>      — 运行指令（simulate, train, experiment, quick-test, ...）
```

**关键改动：**
- `--` 全部替换为空格分隔（tune/mount 使用纯 positional args）
- Session 持久化到 `.fls_session.json`（tune/mount 写入，run 消费）
- 参数优先级：CLI --覆盖 > session 值 > 默认值
- 自定义 help 输出（`fls help` 或 `fls -h` 显示分类布局）
- Tab 补全支持（argcomplete + PowerShell 脚本）
- `.gitignore` 添加 `.fls_session.json`
- `CLI_REFERENCE.md` 全面重写
- 核心实验逻辑复用原有 `_cmd_simulate` 等函数
- ruff 零告警 + 10 项烟雾测试全部通过

## non-IID 小样本 + 数据截断 + 训练前基线评估

问题：FL 训练初始准确率直接 0.92+（因为 MNIST IID + 每个客户端 5 epoch 全量数据）

修复链：
1. `FLConfig` 新增 `classes_per_client: int = 2` + `max_samples_per_client: int = 1000` 字段
2. `runner.py prepare_data()` 新增类别等比例截断逻辑（先按类别分组再截断）
3. `runner.py run()` 从 `self.config` 自动读取数据划分参数，支持方法参数覆盖
4. `server.py run_sync()` 新增训练前基线评估：`round_num=-1` 记录随机模型准确率
5. `config.py` 三个算法预设全部默认 `classes_per_client=2, max_samples_per_client=1000`
6. `cli.py` session 默认 `non_iid=True, classes_per_client=2, max_samples=1000`
7. `standard_experiment.py` 两个函数签名新增 `non_iid/classes_per_client/max_samples_per_client`
8. PowerShell 补全列表新增 `classes-per-client`, `max-samples`

50 轮测试效果：基线 8.87% → 第1轮 30.67% → 最终 45.06%（真实学习曲线，不再 92% 起步）
