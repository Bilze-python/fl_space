# 太空联邦学习评测指标说明

公开演示知识库笔记：统一指标口径，避免"数值看起来对、结论却不可比"。

## 模型侧

- **最终准确率**：最后一次评估的聚合准确率；
- **峰值准确率**：整个过程中出现过的最高准确率；
- **准确率增益**：开启某机制（如卸载）相对对照组的差值；
- **收敛轮次**：首次达到"最终准确率 − 2%"的轮次；
- **尾部稳定性**：最后若干轮准确率的标准差，反映是否震荡。

## 系统侧

- **每轮时长（小时）**：从下发全局模型到本轮聚合完成的仿真时间；
- **单星空闲时间（小时）**：卫星既不在计算也不在通信的累计时间；
- **到达目标精度所需仿真天数**：衡量"从几个月缩短到几天"这类结论；
- **通信/卸载开销**：累计卸载样本数、累计时隙、模型传输量。

## 统计侧

- 至少 3–5 个随机种子，报告均值 ± 标准差；
- 单 seed 结果只能作为功能验证，不能作为显著性证据；
- 横向比较时必须对齐：数据集划分、模型结构、超参、窗口生成方式、评估频率。

## 常见误区

1. 把"时隙数"直接当作真实秒数；
2. 只报告准确率、不报告样本是否守恒；
3. 把轻量离散仿真的结果写成"复现论文数值"。
