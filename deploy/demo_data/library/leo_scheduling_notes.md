# LEO 卫星联邦学习的通信调度要点

> 面向公开演示的知识库笔记：说明"什么时候能训练/聚合"这件事为什么比算法本身更关键。

## 三个约束

1. **间歇连接**：卫星与地面站的可见窗口通常只有 5–15 分钟，两次可见之间可能间隔 90–180 分钟；不存在"随时可通信"的假设。
2. **确定性但异构**：轨道可预测，但每颗卫星的窗口时刻不同，因此客户端可用性天然不均衡。
3. **客户端少、单点权重大**：星座规模远小于地面 FL，每颗卫星的更新对全局模型影响更大，调度不当会放大偏差。

## 调度能带来什么

- 优先选择"首次接触 + 再次接触"总时间最短的卫星，可以缩短每轮聚合的等待；
- 把同簇卫星安排在相邻时段接触同一地面站，能减少跨轨道面的等待；
- 但过度压缩每轮计算时间会让本地 epoch 不足，导致准确率下降——需要"最小本地 epoch"约束。

## 评价指标

- 每轮时长（仿真小时，不是墙钟时间）；
- 单星空闲时间（既不算也不通信的时间）；
- 到达目标准确率所需的轮次与仿真天数；
- 聚合准确率随轮次/仿真时间的变化曲线。

## 复现注意事项

窗口由轨道几何与最小仰角决定；用不同轨道库（STK、Skyfield、Orekit）得到的窗口会有分钟级差异，直接影响轮次时长。报告中必须写明工具、最小仰角与时间步长。
