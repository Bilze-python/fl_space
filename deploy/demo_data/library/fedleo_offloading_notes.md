# FedLEO 卸载机制精读笔记

> 来源：Zhai et al., "FedLEO: An Offloading-Assisted Decentralized Federated Learning Framework for Low Earth Orbit Satellite Networks", IEEE TMC 2024。
> 本文为 SpaceFL 平台自己整理的阅读笔记，不是论文原文，也不代表作者结论。

## 核心思想

LEO 卫星的数据分布会随观测任务变化，单星训练容易过拟合本星数据；同时星间链路让卫星可以把部分样本"卸载"给邻居，用来提升数据均衡度并改善聚合效果。FedLEO 采用去中心化的分层聚合：先在轨道面内聚合，再在轨道面之间聚合，减少对地面站的依赖。

## 卸载在做什么

1. 根据邻居的链路条件与当前负载，选择可卸载的卫星对；
2. 用离散比例（如 0.25/0.5/0.75）搜索卸载量，而不是求解连续最优化；
3. 卸载后重新划分数据，让参与聚合的节点拥有更均衡的类别分布；
4. 用数据均衡熵、准确率与时延共同评价收益。

## 与本文档平台的关系

SpaceFL 平台实现了轻量版"卸载开/关"对照：同一数据划分、同一初始化、同一聚合路径，只切换是否执行卸载。它适合做功能验证与趋势观察，但不等于论文里的 KKT 功率优化与多跳竞争模型。做横向比较时，应把"实现级别"（轻量离散仿真）写入结论。

## 复现提示

- 需要固定随机种子、样本上限与非 IID 划分；
- 至少报告：最终/峰值准确率、准确率差值、累计卸载样本、样本守恒、数据均衡熵、时延时隙；
- 单 seed、5 轮的结论只能说明"机制工作"，不能说明统计显著性。
