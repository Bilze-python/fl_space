# SpaceFL 平台能力与边界（公开演示版）

本页说明在线演示中你能体验什么、不能体验什么，以及为什么这样设计。

## 可以体验

1. **文献库**：全文检索、结构化精读、与研究目标相关度、知识库问答（带页码引用）；
2. **前沿情报**：arXiv/航天资讯的抓取缓存、按研究目标相关度重排、情报简报；
3. **研究智能体**：把自然语言目标转成结构化实验计划（假设/变量/对照/指标/风险/预计耗时），并给出计划评审分数；
4. **结果解读**：对预置实验档案做指标统计、证据链、文献对照与"尚不能支持的结论"。

## 公网演示模式的限制

为防止滥用与保护数据，在线演示只开放"只读 + 分析"能力：

- 不启动新的训练/批量实验；
- 不允许导入文献、修改配置、重建索引、删除档案；
- 文献文件读取限制在演示文献目录内；
- 大模型接口按 IP 限流（默认走离线规则引擎）。

## 技术边界

- 实验执行器当前支持 FedLEO 卸载开/关对照与实验档案分析；
- 时间与功率模型是轻量离散仿真，不等同于论文的连续/优化模型；
- 离线规则引擎的结论由确定性规则生成，与"大模型综合结论"在界面上有明确标识。

## 本地完整体验

在本地运行 `start_spacefl.bat`（8700 端口）可解锁训练、批量实验、文献导入与自定义大模型配置。
